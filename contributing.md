## 🌊 A Cleaner Way to Browse Creator Feeds

**Patreon Content Viewer** is a lightweight, modern web application designed to give you a seamless, distraction-free way to browse publicly available posts from your favorite Patreon creators. 

The official Patreon web interface can be heavy, slow, and cluttered with UI elements you don't need when you just want to view images or read updates. This viewer strips away the noise, providing a fast, gallery-focused experience. It aggregates publicly accessible media, making it incredibly easy to preview portfolios, download high-resolution artwork, and keep track of your favorite creators' public updates — all without requiring an account or logging in.

> 💡 **Why use this viewer?** Because discovering new artists should be frictionless. Skip the heavy scripts, avoid unnecessary tracking, and enjoy a beautiful, responsive gallery that puts the content first.

## 🚀 Quick Start

> **Three steps. Two minutes. No account required.**

### 1️⃣ Access the web app
Click the **Live Viewer** button at the top of this README to open the tool in your browser.

### 2️⃣ Enter a creator's URL
Copy the link of the Patreon creator you want to view (e.g., `patreon.com/creatorname`) and paste it into the search bar.

### 3️⃣ Browse and download
Scroll through the feed. Click any image to view it in full resolution or use the download button to save it.

## ⚙️ How It Works

<div align="center">

| Layer | Responsibility | Tech |
|:---|:---|:---|
| 🕷️ **Scraper Engine** | Fetches public JSON data from Patreon's API | `Axios` / `Node.js` |
| 🎨 **Frontend UI** | Renders the feed with masonry layout | `React` + `TailwindCSS` |
| ⚡ **Caching Layer** | Caches creator data to prevent rate limits | `Redis` (Optional) |
| 🛡️ **Proxy Network** | Rotates IPs to bypass basic blocks | Custom Proxy Middleware |

</div>

The project is built with a modular architecture, separating the data-fetching logic from the UI. This makes it incredibly easy to update the scraper if Patreon changes its API, without touching the frontend code.

## ❓ Frequently Asked Questions

<details>
<summary><b>Is this legal?</b></summary>

This tool is an aggregator for **publicly accessible** content. It does not bypass paywalls or hack into private accounts. It simply formats public data. However, scraping may violate Patreon's Terms of Service. Use this tool for **educational and preview purposes only**.
</details>

<details>
<summary><b>Can I see locked posts?</b></summary>

No. The viewer only displays media that is publicly available on the creator's page. If a post is strictly locked to paying subscribers, it will not appear in the feed.
</details>

<details>
<summary><b>Do I need to log in?</b></summary>

Absolutely not. We strongly advise against entering your credentials anywhere except the official Patreon website. This tool requires no login and operates completely anonymously.
</details>

<details>
<summary><b>How do I update the app?</b></summary>

If you are using the hosted version, it updates automatically. If you are self-hosting, simply run `git pull` and rebuild the project to get the latest features and fixes.
</details>

<details>
<summary><b>How do I report a bug?</b></summary>

Open an issue on the GitHub repository. Include the creator's URL and a screenshot of the error you encountered.
</details>
